The Scripts can be used to analyze metabolomics data, especially untargeted metabolomics data. It can be used to get statitically significant metabolites between two groups. 
The random forest script can be used to perform machine learning analysis of significant metabolites to produce metabolites ranking in the oder of descriminative power between two conditions/groups.
The bayesian and standar logistic regression scripts can be used to perform classification analysis under these two frameworks, to separate two groupd based on metabolite values. It is better to use the statisticlaly significant data.
Other scripts can perform the function as stated in the "name" of the script.
